📊 HR Analytics Dashboard
An interactive Power BI dashboard designed to uncover insights from HR data. Explore employee demographics, attrition trends, hiring patterns, and performance metrics—all in one place.
🚀 Highlights
- Dynamic filters and slicers for deep analysis
- Visualizations of workforce growth and attrition drivers
- Performance and training insights for better decision-making
📂 Files
- HR_Analytics.pbix → Interactive Power BI dashboard
- HR_Analytics.pdf → Static export for quick viewing
🛠️ Usage
- Open the .pbix file in Power BI Desktop for full interactivity
- View the .pdf for a snapshot of the dashboard

✨ This project showcases how data visualization empowers HR teams to make smarter, data-driven decisions.
