## 📌 Executive Summary

**HR Analytics Dashboard** is a comprehensive Power BI solution that transforms raw HR data into actionable workforce insights. It helps HR teams and business leaders understand employee attrition, track hiring trends, monitor performance metrics, and make data-driven talent decisions.

> 💡 **Business Impact**: Reduces employee turnover by identifying attrition drivers, optimizes hiring strategies, and improves workforce planning.

---

## 🎯 Business Problems Solved

| Problem | Solution |
|---------|----------|
| ❌ High employee turnover | ✅ Identify attrition drivers and risk factors |
| ❌ Manual reporting takes days | ✅ Automated dashboard with real-time filters |
| ❌ No visibility into hiring trends | ✅ Track workforce growth and recruitment patterns |
| ❌ Performance data scattered | ✅ Centralized performance and training metrics |

## 🚀 How to Use

### Prerequisites

- Power BI Desktop (free download from Microsoft)
- Windows 10/11 or Power BI Service (cloud)

### Steps

```bash
# 1. Download the dashboard
Download HR_Analytics.pbix from this repository

# 2. Open in Power BI Desktop
Double-click the .pbix file

# 3. Refresh data (if needed)
Click "Refresh" on the Home tab

# 4. Explore interactively
Use slicers and filters to explore different views

# 5. Quick preview (no software needed)
Open HR_Analytics.pdf for a static snapshot
